# QA 체크리스트

시각 계약(`docs/design-contracts/*.md` + `e2e/contracts/*.ts`) 이 커버하지 못하는 **자잘한 인터랙션·시각 편차** 를 사람이 매 세션 확인할 수 있는 체크리스트 모음.

## 배경 (2026-07-31 도입)

- **감사 계약 (시각)** 은 요소의 모양·수치만 검증. 링크 목적지·버튼 클릭 후 흐름은 미검증
- **인터랙션 계약** (`e2e/contracts/interactions-*.ts`) 이 클릭 목적지를 자동 검증하지만, **사용자 경험적 어색함** (예: input 폭이 왜인지 화면마다 달라 보임) 은 여전히 사람 눈이 필요
- 이 체크리스트는 화면 개편·버그 수정 후 **최종 시각 확인** 시 놓치기 쉬운 항목을 명시적으로 관리

## 사용법

1. 화면을 수정한 PR 이면 해당 화면의 체크리스트를 실행
2. 개인 PC (혹은 시각 확인 가능한 세션) 에서 브라우저로 실측
3. 각 항목을 `[x]` 로 표시하며 이상 발견 시 커멘트

## 화면별 체크리스트

| 화면 | 파일 | 최근 갱신 |
|---|---|---|
| 개인정보 수정 | [profile-edit.md](profile-edit.md) | 2026-07-31 |

## 인터랙션 계약과의 관계

- **인터랙션 계약**: 자동 검증 가능한 것 (클릭 후 URL 이동, 모달 노출 등)
- **체크리스트**: 자동화하기 애매한 것 (시각 균형, 폰트 톤, 반응 시간 체감 등)
- 체크리스트 항목이 반복 발견되면 인터랙션·시각 계약으로 승격
