## FAIL 상세 (ym-impl 반려 사항)

### C-1. HomeService.findRecommendedPrograms 중복 ArrayList 복사

**파일**: `src/main/java/io/github/sihyuuun/youthmoa/web/HomeService.java`

**현재 상태**:
```java
// L151-157 (이번 PR 로 추가)
List<Program> pool =
    new ArrayList<>(
        programRepository
            .findAllByIsActiveTrue(…)
            .getContent());
// L158-159 (삭제 안 된 이전 코드)
// Page.getContent() 가 unmodifiable List 반환 → sort 위해 새 ArrayList 로 복사
pool = new ArrayList<>(pool);
```

**문제**: L151~157 에서 이미 `new ArrayList<>(…)` 로 복사했으므로 L159 는 동일 요소를 다시 한 번 복사. 50건 리스트 얕은 복사 1회 추가 — 기능상 무해, 성능 영향 미미, 가독성/의도 혼선.

**기대 vs 실제**:
- 기대: ArrayList 복사 1회
- 실제: ArrayList 복사 2회 + L158 주석이 L159 를 설명하지만 실제 책임은 L151~157 로 이동됨

**재현**: 코드 열람. 테스트는 결과 동일하므로 FAIL 안 됨 (750/750 PASS 유효).

**조치**: L158-159 두 줄 삭제. 또는 L158 주석을 L151 위로 이동.

**심각도**: LOW (데드 코드). 커밋 가능하지만 다음 PR 에서 정리 권장. 또는 이 PR 에 끼워 수정.
