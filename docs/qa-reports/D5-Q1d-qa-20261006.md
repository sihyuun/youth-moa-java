## 4. @NotNull Bean Validation 작동 재검증 — MEDIUM 경고

- `ProgramFormRequest.applyStartDate/applyEndDate` 에 `@NotNull(message="...")` 정상 부착
- **BLOCK 아님 — 서비스 레벨 안전망 작동 확인**:
  - `AdminProgramController.create()` / `update()` 가 `@Valid` 를 **쓰지 않음** → Bean Validation 바인딩 미수행
  - `AdminProgramService.validate(req)` (line 388~390) 가 `req.getApplyStartDate() == null || req.getApplyEndDate() == null` → `IllegalArgumentException("신청 기간을 입력해주세요.")` 로 커버
  - 결과: null 전송 시 400 응답 보장. 다만 **메시지가 서비스 메시지("신청 기간을 입력해주세요.") 로만 노출**되고 DTO @NotNull 메시지("신청 시작일을 입력해주세요.") 는 미사용
- 영향: UX 메시지 정밀도 — 두 필드 중 어느 쪽이 비었는지 구분 안 됨. 운영 UX 정책에 어긋나지는 않으나 D5-Q1d 의 "@NotNull Bean Validation 승격" 의도가 100% 작동하지는 않음
- 조치 제안 (후속 소작업): Controller 에 `@Valid` + `BindingResult` 추가 → form 뷰로 return 하는 경로 작성. 서비스 안전망은 유지
