### 1-2. 설계 의도

- **같은 ProgramCardDto 안에서 뱃지와 서브텍스트의 수치 축 일치**: L78 뱃지 D-day = `getDdayLabel()` (applyEnd 기준), L172 "마감까지 N일" = `getDaysUntilDeadline()` (applyEnd 기준). 교체 후 동일 축.
- **"신청 오픈까지 N일" 라벨과 산술의 축 일치**: 라벨은 "신청 오픈" 축이므로 산술도 applyStartDate 축이어야 함.
- **nullable 폴백 유지**: Program.getDaysUntilApplyStart() / getDaysUntilDeadline() 모두 effective 폴백 (startDate/endDate) 을 포함. D5-Q1d V27 backfill 머지 후 TODO 로 제거 예정. ProgramCardDto 는 폴백 로직을 엔티티에 위임.
