## 화면 1 — WF-5-001-01 프로그램 화면 (진행중인 프로그램)

### Description

**1. [정렬]**
- 프로그램 화면 접속 시 기본값은 `진행중인 프로그램 보기`, `기본 정렬순` 으로 노출됨
- 하단에 노출되는 프로그램 개수가 `전체 (프로그램 수)건` 형태로 노출됨 (진행중인 프로그램 보기: 해당 시 정확 표기 필요)
- 프로그램 정렬은 `기본 정렬순` 으로 적용되어 노출되며 다른 정렬조건 선택하여 조회 가능함
  - **기본 정렬순**: 본인이 즐겨찾기한 프로그램이 먼저 노출되며, 즐겨찾기한 프로그램 없을 경우 최신 등록순으로 노출됨
  - **최신순**: 최신 등록된 프로그램순으로 노출됨 (최신 등록 → 과거 등록 순)
  - **인기순**: 신청자 수 많은 프로그램 순으로 노출됨
- 진행중인 프로그램 없어 `해당 시 전체 프로그램`이 노출되면, WF-5-001-02 화면과 같이 나타남

**2. [프로그램 목록]**
- 프로그램 진행 상태가 badge로 노출됨
  - **진행중**: 신청 기간 중이며, 사용자가 해당 프로그램에 신청 가능한 상태 (파랑 컬러)
  - **마감**: 신청 기간이 지났거나, 모집 인원이 모두 모집되어 사용자가 해당 프로그램에 신청 불가한 상태
- 해당 프로그램마다 진행기간이 노출됨
- (진행중 / 마감 badge)

**3. [필터]**
- 지역/청년센터를 선택하여 프로그램 조회가 가능함
- 기본값은 지역 15개, 청년센터 15개 제공됨 (가나다순)

**4. [Pagination]**
- 노출되는 데이터 많을 경우 페이지네이션 노출됨

**M-1. [정렬] (mobile)**
- 프로그램 화면 접속 시 기본값은 `진행중인 프로그램 보기`, `기본 정렬순` 으로 노출됨
- `기본 정렬순` 클릭 시 드롭다운 노출되며 다른 정렬조건 선택하여 조회 가능함
- `진행중인 프로그램 보기` toggle 버튼 off 시 전체 프로그램이 노출되며, WF-5-001-02 (mobile) 화면과 같이 나타남

**M-2. 스크롤 (mobile)**
- 노출되는 데이터 많을 경우 무한 스크롤

### Button Description

**A. 즐겨찾기** — (Action) 버튼 클릭 시, 해당 프로그램을 즐겨찾기/즐겨찾기 해제할 수 있음

**B. 신청하기** — (Action) 클릭 시, WF-5-002 프로그램 신청 화면으로 이동

**C. 상단 이동 버튼 (Floating Button)** — (Action) 클릭 시, 웹사이트 최상단으로 이동

**D. 지역 더보기** — (Action) 클릭 시, 지역 목록 팝업 노출되며 선택하여 검색 가능함

**E. 청년센터 더보기** — (Action) 클릭 시, 청년센터 목록 팝업 노출되며 선택하여 검색 가능함

**F. 초기화** — (Action) 선택한 조건 없을 경우 버튼 비활성화되어 노출됨

**H. 초기화** — (Action) 클릭 시, 선택한 조건 초기화됨

**G. 확인** — (Action) 클릭 시 선택한 조건이 적용되어 검색 결과 노출됨

**M-A. 필터** — (Action) 클릭 시, 필터 목록 노출되어 선택하여 검색 가능함 (하단 필터 클릭 시_mobile 화면 참고)

**M-B. 신청하기** — (Action) 클릭 시, WF-5-002 (mobile) 프로그램 신청 화면으로 이동

## 화면 2 — WF-5-001-02 프로그램 화면 (전체 프로그램)

> 화면 1(진행중인 프로그램) 에서 `진행중인 프로그램 보기` toggle 을 off 한 상태.

### Description

**1. [정렬]**
- 사용자가 선택한 정렬조건이 있는 상태에서 `진행중인 프로그램만 보기` 해제한 경우 정렬조건은 그대로 적용되어 노출

### Button Description

**A. 신청하기 (Disabled)** — 마감된 프로그램의 경우 버튼 비활성화되어있어 클릭 불가함

## 화면 3 — WF-5-002 프로그램 신청 화면

### Description

**1. [프로그램 정보]**
- 사용자가 선택한 프로그램의 정보가 노출됨

**2. [강좌 선택] Dropdown**
- 강좌 선택이 가능한 프로그램의 경우, 드롭다운 노출됨 (관리자 화면에서 설정한 값에 따라 노출됨)

**3. [신청자 정보]**
- 로그인한 사용자의 정보가 노출되며, 변경 가능함

**4. [추가 정보]**
- 필수 항목
- 관리자가 설정한 추가 정보가 있는 경우 노출됨
- 입력/선택하지 않은 경우, 하단에 헬프 텍스트 제공 (관리자가 직접 추가한 내용이기 때문에 모두 다 필수로 체크)
- 헬프 텍스트 문구: **필수 입력 항목입니다.**

**5. [개인정보 수집 동의]**
- 관리자 화면에서 설정한 프로그램 관련 약관이 노출됨
- 데이터 많아질 경우 스크롤 발생
- 동의하지 않은 경우 하단에 헬프 텍스트 제공
- 헬프 텍스트 문구: **필수 항목입니다.**

### Button Description

**A. 상단 이동 버튼 (Floating Button)** — (Action) 클릭 시, 웹사이트 최상단으로 이동

**B. 신청하기**
- (Action) 버튼 클릭 시, 입력된 내용으로 프로그램이 신청됨
- **미입력** 필수 항목 (추가 정보) 이 존재할 경우, 미입력된 항목 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **필수 입력 항목입니다.**
- **미선택** 필수 항목 (강좌 선택, 개인정보 수집 동의) 이 존재할 경우, 미선택된 항목 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **필수 항목입니다.**
- 성공 시 신청 완료 토스트메시지 노출되며, WF-5-001-01 진행중인 프로그램 화면으로 이동함
  - 토스트메시지 문구: **신청되었습니다.**

## 결정 이력

**2026-07-29 사용자 결정**:
1. **정렬 규칙** → wireframe 채택. `기본 정렬순` = 즐겨찾기 우선 + 즐겨찾기 없으면 최신 등록순 fallback. 이전 Q1 결정(원본 순서)은 폐기.
2. **필터 적용 방식** → 현재 계약(즉시 반영) 유지. wireframe `확인 버튼` 미채택 = **의도적 이탈(deviation)** 로 기록. Reason: 계약 §10-A 이미 확정, prototype 도 즉시 반영 방식.
3. **마감임박순 제거** → wireframe 정렬 목록에 없음 (기본순/최신순/인기순 3종만 정의). 현재 구현의 `deadline` 옵션 제거. 유입되는 `?sort=deadline` URL 은 default 로 fallback (backward compatible).
4. **PR1 구현 완료 (커밋 대기)** — P1 5건 + wireframe 정렬 로직 반영:
   - `notEnded()` Specification 추가 → "전체" 탭에서 종료 프로그램 제외
   - `orderByBookmarkedFirst(Set<Long>)` Specification 추가 → 기본순 로직
   - result-count 를 `.filter-right` 안으로 이동 + htmx OOB swap
   - viewtoggle 에 grid/calendar SVG 아이콘 추가
   - CTA border-radius `--radius-md` → `--radius-pill`
   - 갭 리포트: 58/75 → **62/74 통과** (P1 5건 모두 통과)
