### 화면 1-2 — WF-3-001-01 (신청 내역 존재하는 경우)

**Description**
1. **[기간]** — 기간 선택 시 해당 기간으로 조회 가능. 노출 데이터 없을 경우 스크롤 노출
   - 옵션: **3개월 / 6개월 / 1년 / 3년**
2. **[신청 일시]** — 사용자가 해당 프로그램 신청한 일시 노출. 신청 취소 상태 노출 (`신청 취소한 일시(년월일)에 노출`)
3. **[신청 정보]** — 신청 프로그램의 진행 상태 badge 형태로 노출
   - 대기 / 승인 / 반려 / 취소 badge (아래 색상 4종)
   - 상세는 도메인 상태에 따름
4. **[신청 정보]** — 해당 신청 프로그램 정보 및 신청자 정보가 노출됨
5. **[취소 사유] Radio Button (Disabled)** — 기본 상태는 **Disabled** 상태이며, 취소 시 `신청 취소` 팝업에서 활성화되어 입력 가능
   - 취소 사유 미입력 시 헬프 텍스트: **필수 선택 항목입니다.**

**Button Description**
- **A. 신청 상세** — 승인 상태 신청 상세 (WF-3-001-05)
- **C. 신청 상세** — 대기 상태 신청 상세 (WF-3-001-04)
- **D. 신청 상세** — 반려 상태
- **E. 신청 상세** — 취소 상태 (WF-3-001-06)
- **B. 신청 취소** — 프로그램 신청 취소 확인 팝업 노출
- **F. 재신청** — WF-5-002 프로그램 신청 화면으로 이동
- **G. 신청 취소 (Disabled)** — `취소` 상태 프로그램의 경우 취소 불가하므로 비활성화
- **K. 신청 취소** — 취소 사유 미선택 시 헬프 텍스트 제공, 선택 시 팝업 사라지고 토스트 (`취소되었습니다.`)
- **H. 취소** — 팝업 사라짐 / **I. 확인** — 신청 취소 팝업 노출 / **J. 돌아가기** — 팝업 사라짐

## 그룹 2 — 즐겨찾기한 프로그램

### 화면 2-1 — WF-3-002-01 (즐겨찾기한 프로그램 존재하지 않는 경우)

**[사용자 정보]**
- 로그인한 사용자의 정보가 나타남
  - `반가워요! {이름}님`
  - 해당 사용자가 진행중인 프로그램 / 참여 종료된 프로그램 개수 노출

**Button Description** (그룹 1 화면 1-1 과 동일한 4개 버튼)

### 화면 2-2 — WF-3-002-01 즐겨찾기한 프로그램 목록

**Description**
1. **[즐겨찾기 개수]** — 사용자가 즐겨찾기한 프로그램 개수가 노출됨. 노출 데이터 없을 경우 스크롤 노출
2. **[프로그램 정보]**
   - **즐겨찾기한 최신순**으로 노출됨 (최근 즐겨찾기한 프로그램이 상단)
   - 즐겨찾기한 프로그램은 **최대 20개**까지 가능, 20개 초과 시 오래된 즐겨찾기 프로그램에서 삭제됨
   - 즐겨찾기한 프로그램의 정보 및 즐겨찾기 badge 형태로 노출됨
   - 상태: **진행중 / 마감** badge 로 분류
     - **진행중**: 해당 프로그램 신청 기간 중이며, 신청이 가능한 상태
     - **마감**: 해당 프로그램 신청 기간 종료(만료)되어, 신청이 불가능한 상태

**Button Description**
- **A. 즐겨찾기** — 클릭 시 토스트 후 즐겨찾기 해제 처리 (`즐겨찾기 해제되었습니다.`)
- **B. 신청** — WF-5-002 프로그램 신청 화면으로 이동
- **C. 신청 (Disabled)** — 마감된 프로그램의 경우 비활성화

## 그룹 3 — 개인 정보 수정

### 화면 3-1 — WF-3-003-01 마이페이지 > 개인 정보 수정 (비밀번호 재확인)

**Description**
1. **[사용자 정보]** — 반가워요! {이름}님 + 진행중/참여 종료 프로그램 개수
2. **[아이디]** — 해당 사용자의 아이디가 노출됨, 사용자가 변경 불가함
3. **[비밀번호] input** — 필수 항목
   - 입력하지 않을 경우 헬프 텍스트: **비밀번호를 입력해주세요.**

**Button Description**
- **A. 프로그램 신청 내역** — WF-3-001-01 로 이동
- **B. 즐겨찾기한 프로그램** — WF-3-002-01 로 이동 (우측 badge 개수 노출)
- **C. 개인 정보 수정** — WF-3-003-01 로 이동
- **D. 확인**
  - 비밀번호 미입력 시 input 하단 헬프 텍스트: **비밀번호를 입력해주세요.**
  - 비밀번호 불일치 시 하단 헬프 텍스트: **비밀번호가 일치하지 않습니다.**
  - 비밀번호 일치 시 WF-3-003-02 개인 정보 수정 화면으로 이동

### 화면 3-2 — WF-3-003-02 개인 정보 수정

**Description**
1. **[아이디]** — Disabled 상태로 노출, 변경 불가함
2. **[새 비밀번호] input** — 입력 시 기본은 암호화 처리(*) (WF-2-001-02 `비밀번호` input 참고)
   - 아이콘 클릭하여 입력한 비밀번호 조회 가능 (WF-2-001-02 `비밀번호 확인` input 참고)
   - 텍스트 제한: 공백 불가, **국문·영문·숫자·특수문자 최소 8자~최대 16자**
   - 정책 불일치 시 헬프: **비밀번호는 영문, 숫자, 특수문자 2가지 이상 조합하여 최소 8자 이상 입력되어야 합니다.**
3. **[새 비밀번호 확인] input** — 동일 정책
   - 새 비밀번호와 불일치 시 헬프: **입력한 비밀번호와 일치하지 않습니다.**
4. **[이름] input** — 필수 항목, 공백 불가, 국문·영문 최대 20자
5. **[핸드폰번호] input** — 필수, 숫자만 입력 가능
6. **[성별] Radio Button** — 필수, 선택값: 남 / 여
7. **[생년월일] input** — 필수, 공백 불가, **숫자 최대 8자**까지 입력 가능

**Button Description**
- **A. 재검색** — 주소 검색 팝업 노출 → 저장 후 반영
- **B. 탈퇴하기** — 탈퇴 확인 팝업 노출
- **C. 회원정보 수정**
  - 미입력 필수 항목 존재 시 하단 헬프: **필수 입력 항목입니다.**
  - 성공 시 토스트 (`회원 정보가 수정되었습니다.`) + WF-3-003-01 개인 정보 수정 (비밀번호 재확인) 화면 노출
- **D. 취소** — 팝업 사라짐
- **E. 확인** — 회원 탈퇴처리되어 로그인 화면으로 이동, 토스트 (`탈퇴처리되었습니다.`)
