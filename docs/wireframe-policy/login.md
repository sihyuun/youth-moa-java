## 화면 1 — WF-1-001 로그인 화면

### Description

**[아이디] Input**
- 필수 항목

**[비밀번호] input**
- 필수 항목

### Button Description

**1. 아이디 찾기** — (Action) 버튼 클릭 시, `WF-1-002-01 아이디 찾기 > 가입 정보 입력` 화면 노출됨

**2. 비밀번호 찾기** — (Action) 버튼 클릭 시, `비밀번호 찾기` 화면 노출됨
- 미입력된 필수 항목이 존재할 경우, 미입력된 항목 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **필수 입력 항목입니다.**
- 성공 시 토스트메시지 제공 후, 로그인 화면으로 이동
  - 토스트메시지 문구: **저장되었습니다**

**3. 로그인** — (Action) 버튼 클릭 시, 입력된 정보로 로그인
- 미입력된 항목이 존재할 경우, `비밀번호` 항목 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **아이디 또는 비밀번호를 입력해주세요.**
- 성공 시 메인 화면으로 이동
- 로그인 정보가 일치하지 않는 경우, `비밀번호` 항목 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **아이디, 비밀번호를 확인해주세요.**

**4. 회원가입** — (Action) 버튼 클릭 시, WF-2-001 회원가입 화면으로 이동

**확인** — (Action) 버튼 클릭 시, 일치하는 회원 정보가 있을 경우 `WF-1-002-02 아이디 찾기 > 아이디 찾기` 화면 노출됨

## 화면 5 — WF-1-003-02 비밀번호 재설정

### Description

**[새 비밀번호] Input**
- 텍스트 제한
  - 공백 입력 불가능
  - 국문, 영문, 숫자, 특수문자 최소 8자~최대 16자까지 입력 가능
- 비밀번호 정책과 일치하지 않을 경우 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **비밀번호는 영문, 숫자, 특수문자 2가지 이상 조합하여 최소 8자 이상 입력되어야 합니다.**

**[새 비밀번호 확인] input**
- 필수 항목
- 텍스트 제한
  - 공백 입력 불가능
  - 국문, 영문, 숫자, 특수문자 최소 8자~최대 16자까지 입력 가능
- 비밀번호 정책과 일치하지 않을 경우 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **비밀번호는 영문, 숫자, 특수문자 2가지 이상 조합하여 최소 8자 이상 입력되어야 합니다.**
- 비밀번호와 일치하지 않을 경우 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **입력한 비밀번호와 일치하지 않습니다.**

### Button Description

**확인** — (Action) 버튼 클릭 시, 비밀번호가 일치하는 경우 토스트메시지 제공 후, WF-1-001 로그인 화면으로 이동
- 토스트메시지 문구: **변경되었습니다**
- 새 비밀번호와 새 비밀번호 확인 input에 입력한 비밀번호가 다를 경우, 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **입력한 비밀번호와 일치하지 않습니다.**
