## 화면 1 — WF-2-001 회원가입 화면

### Description

**1. [아이디] input**
- 필수 항목
- 텍스트 제한
  - 표준 이메일 형식을 따름
  - 유효한 이메일 형식이 아닐 경우 항목 하단에 헬프 텍스트 제공
    - 헬프 텍스트 문구: **올바른 이메일을 입력해주세요.**

**2. [비밀번호] input**
- 필수 항목
- 입력 시 기본은 암호화처리(*) 처리되어 노출됨 (WF-2-001-02 `비밀번호` input 참고)
- 아이콘 클릭하여 입력한 비밀번호 조회 가능 (WF-2-001-02 `비밀번호 확인` input 참고)
- 텍스트 제한
  - 공백 입력 불가능
  - 국문, 영문, 숫자, 특수문자 최소 8자~최대 16자까지 입력 가능
- 비밀번호 정책과 일치하지 않을 경우 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **비밀번호는 영문, 숫자, 특수문자 2가지 이상 조합하여 최소 8자 이상 입력되어야 합니다.**

**3. [비밀번호 확인] input**
- 필수 항목
- 입력 시 암호화처리(*) 처리되어 노출
- 텍스트 제한
  - 공백 입력 불가능
  - 국문, 영문, 숫자, 특수문자 최소 8자~최대 16자까지 입력 가능
- 비밀번호 정책과 일치하지 않을 경우 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **비밀번호는 영문, 숫자, 특수문자 2가지 이상 조합하여 최소 8자 이상 입력되어야 합니다.**
- 비밀번호와 일치하지 않을 경우 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **입력한 비밀번호와 일치하지 않습니다.**

**4. [이름] Input**
- 필수 항목
- 텍스트 제한
  - 공백 입력 불가능
  - 국문, 영문으로 최대 20자까지 입력 가능

**5. [핸드폰 번호] input**
- 필수 항목
- 텍스트 제한
  - 숫자만 입력가능

**6. [성별] Radio Button**
- 필수 항목
- 선택값: 남, 여

**7. [생년월일] input**
- 필수 항목
- 텍스트 제한
  - 공백 입력 불가능
  - 숫자, 특수문자만 입력 가능

**8. [이용약관 동의] Checkbox**
- 필수 항목
- Check하지 않은 경우 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **필수 항목입니다.**

### Button Description

**중복확인**
- (Action) 버튼 클릭 시, 아이디 input 내에 입력된 이메일에 대한 중복체크
- 이메일 형식이 잘못된 경우, 아이디 input 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **아이디 중복확인을 해주세요.** *(또는 형식 오류 시 "올바른 이메일을 입력해주세요.")*
- 중복된 이메일인 경우, 아이디 input 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **이미 등록되어 있는 이메일입니다.**
- 사용가능한 이메일인 경우, 아이디 input 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **사용 가능한 이메일입니다.**

**주소 검색**
- (Action) 버튼 클릭 시, 주소 검색 팝업 노출
- 미입력된 필수 항목이 존재할 경우, 미입력된 항목 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **필수 입력 항목입니다.**
- 주소 검색 팝업에서 기본 주소 검색 가능하며, 입력 후 `저장` 버튼 클릭 시 WF-2-002 회원가입 기본 주소가 노출되며 하단 상세 주소 input 활성 처리되며 노출됨

**가입하기**
- (Action) 버튼 클릭 시, 입력된 내용으로 회원 정보 생성
- 미입력된 필수 항목이 존재할 경우, 미입력된 항목 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **필수 입력 항목입니다.**
- 성공 시 토스트메시지 제공 후, WF-1-001 로그인 화면으로 이동
  - 토스트메시지 문구: **가입되었습니다.**

## 화면 2 — WF-2-002 회원가입 화면 (정보 입력 후 / 주소 검색 후)

### Description

**[비밀번호 확인] input**
- 입력한 비밀번호와 일치하지 않을 경우 input 오른 스타일 노출되며 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **입력한 비밀번호와 일치하지 않습니다.**

### Button Description

**중복확인**
- (Action) 아이디 없이 버튼 클릭 시, 아이디 input 내에 입력된 이메일에 대한 중복체크 (화면 1과 동일 검증 로직)

**재검색**
- (Action) 버튼 클릭 시, 주소 검색 팝업 노출됨
- 주소 검색 팝업에서 새로운 주소 선택하여 입력 후 `저장` 버튼 클릭 시 해당 주소로 업데이트되어 노출됨

**가입하기**
- (Action) 버튼 클릭 시, 입력된 내용으로 회원 정보 생성
- 미입력된 필수 항목이 존재할 경우, 미입력된 항목 하단에 헬프 텍스트 제공
  - 헬프 텍스트 문구: **필수 입력 항목입니다.**
- 성공 시 토스트메시지 제공 후, WF-1-001 로그인 화면으로 이동
  - 토스트메시지 문구: **가입되었습니다.**

## 결정 대기 항목

1. **아이디 = 이메일** 라벨 통일 (전 화면 일관성)
2. **비밀번호 상한 16자 및 국문 허용** 최종 확정
3. **성별·생년월일 필수 여부** — wireframe = 필수. prototype·현재 다를 수 있음
4. **이용약관 세분화** — wireframe 1개 vs prototype 4개 분리
5. **관심 지역·카테고리** — wireframe 스코프 외. 현재 구현 유지 여부
6. **주소 검색 방식** — 팝업(Daum) vs input
7. **가입 성공 라우팅** — 로그인 vs 자동 로그인
