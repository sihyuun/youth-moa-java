## 화면 1 — WF-4-001-01 홈 화면

### Description

**[프로그램]**
- 웹사이트 내에 등록된 프로그램이 나타남
- 최신 등록된 프로그램부터 최대 30개까지 노출됨

**[공지사항]**
- 웹사이트 내에 등록된 공지사항이 나타남
- 최신 등록된 공지사항부터 최대 4개가 노출됨

**[공간안내]**
- 청년센터 내 공간사진이 이미지 움직이는 형태로 노출됨

### Button Description

**A. 프로그램 바로가기** — (Action) 클릭 시, WF-5-001-01 프로그램 화면으로 이동

**B. 프로그램 더보기 (다음)**
- (Action) 클릭 시, 프로그램 4개씩 신규 노출되며, 좌측에 프로그램 더보기 (이전) 버튼 노출됨 (WF-04-001-02 화면 A 버튼 참고)
- 최대 30개만 노출되며, `>` 버튼 클릭 시 전체보기 노출됨 (WF-04-001-02 화면 B 버튼 참고)

**신청하기** — (Action) 클릭 시, WF-5-002 프로그램 신청 화면으로 이동

**공지사항 바로가기** — (Action) 클릭 시 공지사항 화면으로 이동

**공지사항 상세 보기** — (Action) 클릭 시 해당 공지사항 상세 화면으로 이동

**상단 이동 버튼 (Floating Button)** — (Action) 클릭 시, 웹사이트 최상단으로 이동

**B. 프로그램 전체보기** — (Action) 클릭 시, WF-5-001-01 프로그램 화면으로 이동
