## 화면 1 — WF-6-001 공지사항 화면

### 화면 개요

청년모아 웹사이트 공지사항 화면

### Description

**[정렬]**
- 공지사항 화면 접속 시 기본값은 **`전체`** 로 노출됨
- 하단에 노출되는 프로그램 개수가 `전체 {공지사항 수}건` 형태로 노출됨 (`{구분값}` 선택 시 해당 구분값의 공지사항 수 노출)
- 공지사항 정렬은 `전체` 로 적용되어 노출되며 다른 구분값 선택하여 조회 가능함

**[고정]**
- 최신 등록된 공지사항부터 10개가 노출되며, 관리자가 등록 시 고정한 공지사항이 있을 경우 해당 공지사항부터 노출됨
- 고정 가능한 공지사항 개수 제한은 없음

**[Pagination]**
- 공지사항은 한 페이지에 **10개까지** 노출되며, 많아질 경우 Pagination 노출됨

### Button Description

- **(공지사항 클릭)** — (Action) 클릭 시, WF-6-002 공지사항 상세 화면으로 이동

공지사항 상세 화면

## 결정 대기 항목

1. **구분(카테고리) 종류** — wireframe 은 `{구분값}` placeholder 만 있음. 실제 값 결정 필요 (예: 공지·이벤트·모집 등)
2. **첨부파일 기능 도입** — 스키마·스토리지 결정 필요 (현재 스코프 외)
3. **고정 공지 정렬 로직 검증** — `isPinned DESC, createdAt DESC` 인지 실측 필요
4. **페이지당 10개 채택 여부** — 현재 구현 수치와 대조
