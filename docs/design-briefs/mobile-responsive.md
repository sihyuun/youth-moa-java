# 모바일 반응형 디자인 브리프 (Claude Design 위임용)

> 작성 260820. 현재 프로젝트는 desktop-first 로만 구축되어 있으며 모바일 반응형은 정책 페이지 + 사이트 헤더 두 곳만 대응. 나머지 화면은 375px 뷰포트에서 레이아웃이 붕괴함.
> 이 문서는 Claude Design 세션에서 화면별 모바일 시안을 산출하기 위한 요구사항·제약·현황을 정리한다.

---

## 1. 목적

- 전 화면을 데스크톱과 동일 UX·정보 밀도를 유지하면서 **375~767px 뷰포트** 에서 시각·기능 붕괴 없이 렌더
- 산출물: 페이지별 모바일 시안 (Figma 등) → 개발이 이를 CSS media query 로 이식

## 2. 산출 기대치

Claude Design 이 반환해야 할 것:

1. **브레이크포인트 정책** — 프로젝트 표준 몇 개 (예: 375 · 768 · 1024 · 1440) · 각 구간에서 무엇이 바뀌는가
2. **공통 컴포넌트 시안** — 헤더 · 푸터 · 카드 · 폼 · 모달 · 탭·필터 pill · 테이블 → 리스트 변환
3. **화면별 시안** — 아래 §5 화면 목록 순
4. **햄버거 / 모바일 메뉴** — 헤더 3링크(프로그램·청년센터·공지사항) 접근 경로. 현재는 hidden 상태
5. **자산 요구** — 신규 아이콘 (햄버거·close-menu·필터 드로어 등) 이 있으면 요청

## 4. 제약

### 마크업 변경 최소화
- HTML 구조 (`<div>` 순서·계층) 는 유지하고 CSS media query 로 재배치 원칙
- 마크업 변경 필요한 경우 (예: 햄버거 메뉴 추가) 는 시안에 별도 표시

### 데스크톱 계약 유지
- 데스크톱 (≥ 768px) 에서는 현재 계약값 (px·색·폰트) 완전 유지
- 모바일 시안에서 데스크톱 값 변경 요구는 별도 flag

### 디자인 토큰 재사용
- `--color-*` `--radius-*` `--shadow-*` 등 기존 토큰 사용. 새 색·radius 신설은 최소화

### 접근성
- 최소 터치 타겟 44×44px (WCAG)
- 텍스트 최소 14px (모바일 가독성)

## 5. 화면별 현황 · 요구

### 5.1 홈 `/`

**현재 데스크톱 (`prototype.tsx L499~694`)**:
- Hero (배너 이미지 배경) + 검색바 + 카테고리 pill 6개
- Quick Stats 3개 (모집중·청년센터·누적참여자)
- 프로그램 섹션 (최대 4개, 4열 그리드)
- 공지 섹션 (대표 1 + 서브 3)
- 공간 안내 3개

**모바일 375 현재 상태**: 아래로 자연 stack 되나 카드 폭 좁아 카드 내 텍스트가 세로 쪼개짐. 카테고리 pill 겹침.

**요구 사항**:
- Hero 높이·배경 이미지 crop 정책 (모바일에서 잘림 어디까지 허용)
- 검색바 폭 (모바일 100% - padding 예상)
- 카테고리 pill 배치 (2행 3열? 스크롤?)
- 프로그램 카드 4열 → 1~2열 (가로 스크롤 캐러셀? 세로 스택?)
- 공간 카드 3개 배치

### 5.2 프로그램 목록 `/programs`

**현재 데스크톱**: 상단 필터 탭 (전체/모집중/진행예정/종료) + 지역·청년센터·정렬 select · 카드 그리드 (3열)

**모바일 375 현재**: 필터 탭 · pill 모두 세로 쪼개짐. 카드 3열 강제로 각 카드 극소 폭.

**요구 사항**:
- 필터 배치 (드로어? 축소 pill? 상단 sticky?)
- 정렬 select 배치
- 카드 그리드 → 1열 세로 스택 또는 2열
- 페이지네이션 하단 스타일

### 5.3 프로그램 상세 `/programs/{id}`

**현재 데스크톱**: 좌 이미지 + 우 정보 카드 · 하단 sticky CTA 바 · 관련 프로그램 캐러셀

**모바일 375 현재**: 좌/우 스택되지만 sticky CTA 폭 붕괴 예상 (미확인)

**요구 사항**:
- 이미지 → 정보 세로 스택 여부
- sticky 하단 바 모바일 대응 (버튼·상태·D-day)
- 관련 프로그램 캐러셀 스와이프 여부

### 5.4 청년센터 `/centers`

**현재 데스크톱**: 좌 필터 + 지도 + 우 센터 카드 리스트

**요구 사항**:

- 지역 select 배치
- "운영 중만 보기" 토글 배치

### 5.5 공지사항 `/notices`

**현재 데스크톱**: 카테고리 pill 5개 (전체/행사/공지/운영/기타) + 5열 테이블 (No/구분/제목/작성일/조회수)

**모바일 375 현재**: pill 5개 세로 쪼개짐 · 테이블 컬럼 폭 붕괴

**요구 사항**:

## 7. 참고 · 특이사항

- **prototype.tsx 는 모바일 시안이 없음** — 데스크톱 단일 소스. 모바일 UX 는 Claude Design 이 자유롭게 제안 가능하되 P-1 (카피) · P-3 (아이콘) 정책은 준수
- **wireframe.png 는 정책 페이지 §5.19 만 모바일 언급** — 다른 화면 wireframe 은 데스크톱 기준. 새 wireframe 만들지 사용자에게 확인
- **디자인 토큰은 `main.css :root` 참조** (색·radius·shadow)
- **폰트는 Pretendard** (CDN 로드)
- **HTMX 인터랙션** — 모바일에서도 그대로 동작 (조회 상태 전환 등). 시안은 정적 상태 위주로 설계하고 인터랙션은 데스크톱과 동일 채택
