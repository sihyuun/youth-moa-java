# Handoff: 청년모아 관리자 페이지 (Youth-MOA Admin)

> **최신 갱신본** — 인디고 팔레트 + 폼 검증 · 삭제 확인 모달 · 접근성 · 로딩 스켈레톤 · 에러/재시도 상태 · 반응형 · 마이크로카피 톤까지 반영.

## Overview
청년 대상 프로그램을 운영하는 청년센터 통합 관리자 페이지입니다. 관리자가 프로그램(강좌 포함)을 등록·수정·관리하고, 사용자(회원)와 신청 현황을 관리하며, 방문자·신청 통계를 확인할 수 있는 웹 어드민입니다. 인증(로그인/회원가입/아이디·비밀번호 찾기) 플로우와 마이페이지도 포함합니다.

---

## About the Design Files
이 번들의 `청년모아 Admin.dc.html` 은 **HTML로 제작된 디자인 레퍼런스(프로토타입)** 입니다. 의도한 화면 구성·인터랙션·동작을 보여주는 참고용이며, 그대로 프로덕션에 복사해 쓰는 코드가 아닙니다.

작업 목표는 이 HTML 디자인을 **대상 코드베이스의 기존 환경(React/Next.js, Vue 등)과 패턴·라이브러리를 사용해 재구현**하는 것입니다. 아직 환경이 없다면 프로젝트에 가장 적합한 프레임워크를 선택해 구현하세요. 함께 제공되는 `prototype.tsx` 는 React + TypeScript 기준의 **구조 스캐폴드**로, 화면 라우팅·상태·데이터 모델·컴포넌트 분해의 출발점입니다.

- `청년모아 Admin.dc.html` — 디자인/동작의 원본 진실(Source of truth). 브라우저로 직접 열어 모든 화면과 인터랙션을 확인하세요. (Design Component 런타임 `support.js` 필요)
- `support.js` — HTML 프로토타입 구동용 런타임. **재구현 대상이 아님** (참고용).
- `prototype.tsx` — React/TS 재구현 스캐폴드.
- `assets/` — 로고 이미지 (`logo_primary.png` 밝은 배경용, `logo_white.png` 다크 헤더용).

## 전역 레이아웃 (Admin)

```
┌──────────────────────────────────────────────────────────────────────┐
│ HEADER (다크 #111827, height 56px, position:sticky top:0, z-index 500) │
│  [로고+ADMIN] [센터스코프▾] [권한전환▾]   (GNB 절대중앙)   [검색][🔔][👤]│
├──────────────────────────────────────────────────────────────────────┤
│                                                                        │
│  MAIN (배경 #FAFAFB, padding 24px 28px) — 페이지 전체 스크롤            │
│   각 화면(screen)이 여기 렌더. 내부 콘텐츠 max-width 없음(풀폭)         │
│                                                                        │
├──────────────────────────────────────────────────────────────────────┤
│ FOOTER (콘텐츠와 함께 스크롤, 고정 아님) — 버전/저작권                  │
└──────────────────────────────────────────────────────────────────────┘
```

- 페이지 스크롤은 `body` 전체에서 발생하고 **헤더만 sticky 고정**. (내부 스크롤 컨테이너 금지)
- GNB 메뉴는 헤더 **절대 중앙 정렬**(`position:absolute; left:50%; transform:translateX(-50%)`). 로고는 좌측, 검색/알림/유저는 우측(`flex:1; justify-content:flex-end`).
- 인증 화면(login/signup/find-id/find-pw)은 별도 레이아웃: 밝은 헤더(흰 배경 + `logo_primary.png`) + 가운데 정렬 카드(`max-width:420px`).

## 화면 목록 (screens)

라우팅은 단일 `screen` 상태값으로 전환합니다. 실제 구현 시 URL 라우팅(`/admin/programs` 등)으로 매핑 권장.

### 인증 (별도 레이아웃)
| screen | 화면명 | 설명 |
|--------|--------|------|
| `login` | 관리자 로그인 | 아이디/비밀번호 입력, 미입력 시 인라인 에러 |

| `find-pw` | 비밀번호 찾기 | 단계형: 입력 → 완료(완료 단계엔 "로그인으로 돌아가기" 없음) |

## 🆕 최신 기능 (이번 갱신 반영)

### 1. 폼 검증 (Form Validation)
적용 폼: **프로그램 등록/수정(정보 탭), 사용자 등록, 사용자 상세/수정, 회원가입, 설정-비밀번호 변경.**
- **규칙**: 필수값 + 형식 검증
  - 이메일: `xxx@xxx.xx` 형식
  - 핸드폰: `01012345678` 또는 `010-0000-0000`
  - 비밀번호: 영문+숫자 포함 8자 이상, "비밀번호 확인" 일치, (설정)이전과 동일 금지
  - 모집인원/숫자: 1 이상 정수
  - 기간: 신청 마감 < 진행 시작, 시작 ≤ 종료 순서 검증
- **에러 표시**: 해당 인풋 **빨간 보더(`#EF4444`)** + 필드 하단 **빨간 텍스트(11px)**. 입력/저장 시 실시간 갱신.
- **저장 동작**: 통과 시 화면 이동 + 성공 토스트 / 실패 시 "입력값을 확인해주세요" 토스트 + 에러 노출.
- 구현 참고: 각 폼은 상태에 `xxField`(값) + `xxBorderField`(보더색) + `xxShowErrField`(bool) + `xxErrField`(메시지)를 두고, 저장 시 일괄 검증.

### 2. 삭제 확인 모달 (Confirm Dialog)
파괴적 액션(프로그램 단건/일괄 삭제, 사용자 일괄 삭제, 상세 ⋯삭제)은 즉시 실행하지 않고 **confirm 모달** 1단계를 거침.
- 상태: `confirmDialog: { type, title, message, count? }` (null이면 닫힘).
- 카피 톤: "… 삭제할까요? 삭제 후 복구할 수 없어요." 오버레이/취소 클릭 시 닫힘, 확인 시 실행 + 토스트.

### 3. 접근성 (Accessibility)
- 키보드 `:focus-visible` 인디고 포커스 링(마우스 클릭 시엔 안 보임) 전역 적용.
- 모달 `role="dialog"`. 실구현 시 focus trap 추가 권장.
- **체크박스는 네이티브 `<input type="checkbox">` + `accent-color:#3F30E9`** 사용(커스텀 div 대신 — 상태 렌더 신뢰성·접근성).

### 4. 로딩 스켈레톤 (Skeleton)
- `.sk` 유틸 클래스: `linear-gradient(90deg,#F0EFF3 25%,#E3E1E8 37%,#F0EFF3 63%)` + `shimmer` 애니메이션, radius 6px.
- 테이블/차트/상세 진입 시 로딩 상태에 적용. 실구현 시 데이터 fetch pending에 연결.

### 5. 에러 / 재시도 상태 (Error State)
- 데이터 로드 실패 시 "불러오지 못했어요" + **재시도 버튼** 패턴. 빈 상태(Empty)와 구분.

### 6. 반응형 (적응형) — `@media` 속성 선택자 방식
인라인 스타일을 유지하면서 클래스 추가 없이 **DOM 직렬화된 style 속성을 `[style*="…"]`로 타겟**해 오버라이드.
- React 직렬화 형태 기준(예: `grid-template-columns: repeat(4, 1fr)` — 콜론·콤마 뒤 공백 포함). 선택자도 이 형태로 작성해야 매칭됨.
- **≤1024px (태블릿)**: 스탯 4열→2열, 2단 레이아웃 폭 축소, main `18px 16px`·header `0 16px` 패딩 축소.
- **≤680px (모바일)**: 모든 그리드 1열 스택(스탯·폼 2단·상세·설정·캘린더 패널), GNB 가로 스크롤, 패딩 추가 축소.
- 테이블은 `overflow-x:auto`로 가로 스크롤 유지.
- (HTML 원본 `<style>` 블록 하단의 `@media` 규칙 참고. 실구현 시 CSS 클래스/브레이크포인트 토큰으로 정규화 권장.)

### 7. 마이크로카피 톤
- 전체 UI 문구를 **부드러운 존댓말**로 통일: 토스트 "…했어요/됐어요", 검증 "…아니에요/일치하지 않아요/이어야 해요", 빈 상태 "…없어요", 알림 "…있어요/임박했어요", 에러 "…못했어요". placeholder는 "…입력해주세요" 유지.

## 컴포넌트별 상세

### 헤더 (Header / GNB)
- 높이 56px, 배경 `#111827`, sticky.
- **로고**: `logo_white.png`, height 34px, 클릭 시 대시보드 이동.
- **ADMIN 뱃지**: 10px, `#1E293B` 배경, `#334155` 보더, `#A6A3B3` 텍스트.
- **센터 스코프 셀렉터**: 🏢 아이콘 + 센터명 + ▾. 시스템 관리자는 드롭다운(전체 센터 + 9개 센터), 센터 관리자는 고정 배지.
- **권한 전환(데모용)**: 점선 버튼. 프로덕션에서는 **제거** — 로그인 계정 권한으로 자동 결정.
- **GNB 메뉴**: 통계 / 프로그램 관리 / 사용자 관리. 활성 탭 `rgba(255,255,255,0.12)` 배경 + 흰 텍스트, 비활성 `#9CA3AF`.
- **글로벌 검색**: 180px 인풋. 입력 시 프로그램/사용자 실시간 검색 드롭다운(우측 정렬, 300px). 결과 클릭 → 상세 이동. mouseleave 시 닫힘.
- **알림 벨**: 미읽음 개수 숫자 뱃지(`#E72D0F`). 클릭 시 드롭다운(280–300px): 유형별 컬러 아이콘(승인/마감/가입), 미읽음 dot, 개별 × 삭제(hover), "모두 읽음". 알림 클릭 → 해당 화면 이동.
- **유저 드롭다운**: 아바타. 메뉴 — 내 정보 / 설정 / 로그아웃.
- 모든 드롭다운은 바깥 클릭 시 닫힘(document click 리스너).

### 테이블 (프로그램/사용자/신청자 공통 패턴)
- 카드 컨테이너(흰 배경, radius 12px) 안에 `overflow-x:auto` + CSS Grid 행.
- 헤더 행: 배경 `#F0EFF3`, 하단 보더 `#E3E1E8`. 컬럼명 가운데 정렬 경향, 내용 좌측 정렬.
- 시퀀스 컬럼명은 `#`이 아니라 **`No.`**.
- **체크박스**: 네이티브 `<input type="checkbox">` + `accent-color:#3F30E9`. 헤더 체크박스 = 현재 페이지 전체 선택.
- 선택 시 상단에 다크(`#1E293B`) **일괄 액션바**: "N건 선택됨" + CSV 내보내기 + 삭제(→확인 모달) + 선택 해제.
- **상시 CSV 내보내기 버튼**도 액션 영역에 별도 제공(선택 없이 전체 내보내기).
- 페이지네이션: 프로그램 8건/페이지, 사용자 10건/페이지. 활성 페이지 `#3F30E9` 배경.
- 빈 상태(Empty): 아이콘 + "검색 결과가 없어요" + 안내문. 에러 상태(재시도)와 구분.

### 프로그램 목록 (3가지 뷰)
- 우측 상단 **뷰 토글**(목록/카드/캘린더 아이콘, 세그먼트). 활성 `#3F30E9`.
- **목록형**: 컬럼 — 체크 / No. / 프로그램명(이미지+이름) / 진행기간 / 신청기간 / 신청현황 / 조회수 / 상태 / 관리. 관리 컬럼 = 복제·삭제 아이콘. 프로그램명 클릭 → 상세. 기간 표기 `YYYY-MM-DD ~ YYYY-MM-DD`.
- **카드형**: `repeat(auto-fill,minmax(220px,1fr))` 그리드. 썸네일 + 상태뱃지 + 이름 + 기간 + **신청률 progress bar** + 신청/정원.
- **캘린더형**: 월간 그리드. 이벤트 클릭 → 우측 **슬라이드 패널**(300px, Google Calendar 패턴) 요약 + "상세보기" 버튼. 그리드 `1fr` ↔ `1fr 300px` 전환.

### 프로그램 상세
- 상단: 프로그램명 + 상태뱃지 / 우측 `수정` 버튼 + **⋯ 더보기 메뉴**(복제·삭제→확인 모달).
- 좌측 정보 카드(썸네일·청년센터·진행기간·신청기간·모집인원·장소·문의처·첨부) + 우측 설명 카드(설명 없을 수 있음 → 세로 스택).
- 하단 **신청 현황 테이블**: 이메일/성별/핸드폰/접수일시/참여횟수/상태. 상태는 관리자가 **드롭다운으로 직접 변경**(승인/대기/반려 등) + 변경 시 확인 모달.
- **대기자 관리 배너**(정원 초과 시): "대기자 N명" + "정원 초과 시 자동 승인" 토글.

### 프로그램 등록/수정 폼 (탭 3개)
- **프로그램 정보**: 기본 정보. 강좌 제공 "예" 선택 시 강좌 입력 영역 노출. **검증 적용.**
- **신청 정보**: 신청 질문 관리 — 항목 추가/삭제 + **드래그앤드롭 순서 변경**(좌측 핸들). 강좌 제공 "예" 시 강좌 입력.
- **약관 정보**: 약관 제공 "아니오" 선택 시 약관명·내용 숨김.
- 라디오 버튼 전 화면 **통일 스타일**(테두리 없음, 선택 시 primary, 연파랑 배경 없음).
- formMode `edit` 시 데이터 프리필 + 제목 "프로그램 수정".

### 통계
- 방문자 현황: 월별 = **막대(hover 수치 툴팁)**, 연도별 = **꺾은선(area gradient)**. 탭 전환. 연도별은 해당 연도 방문자 + 전년 대비 % 표기.
- 프로그램별 통계 테이블(프로그램명 클릭 → 상세). 신청률 progress bar.
- **성별/연령 분포**: 도넛 차트 + 범례(%).

### 사용자 상세
- 정보 수정 폼(이름·핸드폰·비밀번호 변경 **검증**) + **주소 검색**(버튼명 "검색", 다음 우편번호 모달 형태).
- 프로그램 신청 현황 테이블: "신청 상세" → 신청 상세 모달(신청자 입력 답변 표시), 프로그램명 → 프로그램 상세. 취소 상태는 드롭다운 아님, **뱃지 "취소" 표기**.

### 설정 (탭 3개)

## 인터랙션 & 동작
- **화면 전환**: 단일 `screen` 상태(실구현은 라우터). "5번 슬라이드" = 사람 기준 5번째.
- **Toast**: 4타입(success/error/warning/info) — 타입별 아이콘·색. 주요 액션 후 노출, 2.8초 자동 소멸, 하단 중앙 고정. 문구는 존댓말 톤.
- **드롭다운/팝오버**: 바깥 클릭 닫힘. 검색은 mouseleave로도 닫힘.
- **드래그앤드롭**: 신청 질문 순서 변경.
- **모달**: 신청 상세, 상태 변경 확인, 삭제 확인, 주소 검색, 캘린더 날짜 팝업. 오버레이/× 클릭 닫힘, `stopPropagation`.
- **체크박스 일괄 선택 + 액션바** 패턴(프로그램/사용자/신청자).
- **자동 결정 프로그램 상태**: status는 신청기간·정원으로 파생 → **일괄 상태 변경 기능은 의도적으로 제외**. 일괄 액션은 CSV/삭제만.

## State Management
`prototype.tsx` 의 `AppState` 참고. 핵심:
- `screen` — 현재 화면 / `confirmDialog` — 삭제 확인 모달
- `adminRole`('system'|'center') / `adminCenter` / `centerScope` — 센터 데이터 격리
- `programFilter` / `programSearch` / `programView`('list'|'card'|'calendar') / `programPage` / `programSelected[]`
- `userRoleFilter` / `userSearch` / `userPage` / `userSelected[]`
- `formMode`('create'|'edit') / `formTab` / `selectedProgram` / `selectedUser`
- 각 폼의 검증 필드(`pf*`, `uf*`, `udf*`, `signup*`, `pw*` 등): 값 + 보더색 + showErr + errMsg
- `chartMode`('month'|'year') / `calendarView` / `calendarYear` / `calendarMonth`
- `settingsTab` / `notifItems[]` / `toast{msg,type}` / 각종 드롭다운 open 플래그 / 로딩·에러 플래그

### 센터 데이터 격리 (RBAC / 멀티테넌시)
- **센터 관리자**: 본인 소속 센터(`adminCenter`) 데이터만. 센터 스코프 고정.
- **시스템 관리자**: 전체 + 헤더 센터 셀렉터로 특정 센터 필터.
- 유효 센터 = `adminRole==='center' ? adminCenter : (centerScope==='전체' ? null : centerScope)` → 프로그램/통계/대시보드 필터링.
- 프로그램 등록 시 센터 관리자는 소속 센터 자동 고정.
- (헤더 "권한 전환" 버튼은 데모용 — 실제로는 로그인 권한으로 결정, 제거할 것.)
